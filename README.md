# 🛒 Supermarket Sales Analytics Software

An end-to-end data analytics solution built to explore, visualize, and extract insights from supermarket sales data. This project includes both a comprehensive Jupyter Notebook for static exploratory data analysis (EDA) and a dynamic, interactive web dashboard built with Streamlit and Plotly.

## 🌟 Features

- **Dynamic Data Upload**: Supports uploading custom `.csv`, `.xlsx`, or `.ods` sales datasets directly through the UI.
- **Smart Column Mapping**: Automatically detects and maps your dataset columns to the required analytical fields (Sales, Product, Category, Branch, Payment, etc.).
- **Premium User Interface**: Built with an "Ethereal Glass" aesthetic, featuring a dark OLED theme, glass-morphic cards, and custom typography.
- **Interactive Visualizations**: 11 unique, interactive Plotly charts with hover tooltips, zooming, and panning capabilities.
- **Comprehensive Analysis Tabs**: Segmented analysis for Products, Branches, Categories, Payments, Customers, and Ratings.
- **Data Export**: Explore raw data with a built-in correlation matrix and download the processed dataset as a CSV.

## 🚀 Setup & Installation

The project uses a Python virtual environment to manage dependencies cleanly.

1. **Open a terminal/command prompt** and navigate to the project directory:
   ```cmd
   cd c:\house_price_project
   ```

2. **Activate the virtual environment**:
   ```cmd
   .venv\Scripts\activate
   ```

3. **Install dependencies** (if not already installed):
   ```cmd
   pip install -r requirements.txt
   ```
   *(Note: The environment may already be fully configured).*

## 🏃 Running the Application

With the virtual environment activated, you can run the interactive dashboard:

```cmd
streamlit run app.py
```
This will start a local web server. Open your browser and navigate to `http://localhost:8501` to view the dashboard.

To view the static analysis, launch Jupyter:
```cmd
jupyter notebook supermarket_sales_analysis.ipynb
```
